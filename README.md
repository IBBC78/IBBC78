## Mes projets 🚀

### 1.  **CY FISH : Développement d'un Jeu sur Terminal (Pingouins sur un Iceberg)**
   **Technologies utilisées** : C, Algorithmes, Développement de jeux  
   **Mission** : Création d'un jeu en C où des pingouins s’affrontent sur un iceberg pour attraper le plus de poissons. Le jeu utilise une grille hexagonale et des déplacements stratégiques, avec une mécanique de collecte de poissons et un système de blocage de cases. Chaque joueur doit optimiser les déplacements de ses pingouins pour maximiser son score.

### 2. **MarvelTravel : Développement d'un Site Web pour une Agence de Voyages fictive**
   **Technologies utilisées** : HTML, CSS, PHP, JavaScript (DOM, requêtes asynchrones)  
   **Mission** : Création d'un site web pour une agence de voyages permettant aux utilisateurs de choisir des séjours "pseudo-sur-mesure". Le site permet aux utilisateurs de sélectionner des circuits prédéfinis, de modifier certaines options (hébergement, transport, etc.) et de procéder à un paiement en ligne. Le projet a été réalisé en plusieurs phases fonctionnelles avec une approche itérative (HTML + CSS, PHP, JavaScript).
